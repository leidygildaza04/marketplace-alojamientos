Acuerdos de trabajo ya establecidos:

- Cada historia la sube a GitHub la persona asignada en Jira, con su propia cuenta.
- Las ramas se llaman con el código de la historia, por ejemplo `SCRUM-14-registro-con-rol`.
- Los commits empiezan con el código de la historia.
- Todo Pull Request necesita al menos una revisión de otro integrante antes del merge.
- No se hace push directo a `main`.
